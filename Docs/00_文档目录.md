# 轮腿并联腿控制文档目录

> 本目录中的“并腿”统一指平面五连杆并联腿：两只髋关节电机驱动两根主动杆，两根从动杆在轮轴处闭合。它不是“左右两条腿并在一起”，也不是二关节串联腿。

## 阅读约定

- 所有三角函数输入均为 **rad**，显示时才换算为度。
- 长度单位为 m，速度为 m/s，力为 N，力矩为 N·m，时间为 s。
- 数学推导使用单腿局部坐标：原点在后髋关节 A，`+x` 向前，`+y` 向下。这与当前 C 代码一致。
- 图形界面经常使用 `+z` 向上，因此图形坐标与控制代码的 `y` 轴符号可能相反。移植时必须选择一种约定并在传感器入口统一转换。
- `phi1`、`phi4` 是两个主动髋角；`phi2`、`phi3` 是闭链计算出的从动杆绝对角。
- `phi0` 是虚拟腿相对 `+x` 的角，`theta` 是虚拟腿相对世界竖直方向的倾角，两者不能混用。
- 公式中的下标从 1 开始是为了阅读；C 数组下标从 0 开始，映射表在第二篇文档中给出。

## 公式依据标签

正文会用以下标签注明每一步的来源：

| 标签 | 含义 |
|---|---|
| **[解析几何]** | 点坐标、距离、圆交点、三角恒等式 |
| **[闭链约束]** | 刚性杆长度不变形成的约束方程 |
| **[链式法则]** | 对位置或约束关于时间求导 |
| **[刚体速度]** | 平面转杆端点速度 `v = l·角速度·切向单位向量` |
| **[虚功原理]** | 理想约束不做虚功，输入输出瞬时功率相等 |
| **[牛顿第二定律]** | 合力等于质量乘加速度 `ΣF = ma` |
| **[欧拉转动定律]** | 合力矩等于转动惯量乘角加速度 `Στ = Iα` |
| **[线性化]** | 在平衡点保留一阶项，忽略二阶及以上小量 |
| **[最优控制]** | LQR 二次型性能指标与 Riccati 方程 |
| **[数值计算]** | 浮点保护、条件判断、滤波、离散化、限幅 |

## 本文的边界

五连杆几何、雅可比与 VMC 是机构级关系；整车 LQR 还依赖质量、惯量、轮半径、质心和地面接触假设。更改 CAD 质量分布后，几何公式通常仍成立，但 `A/B/K` 矩阵必须重新生成。仿真站稳不能代替低功率悬空、单腿、落地和急停测试。
